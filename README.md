## 👨‍💻 About

Cybersecurity analyst operating as the sole security profile inside a regulated French financial group, working hand in hand with the DSI across the full defensive spectrum. My work sits at the intersection of security operations and engineering: I build detection where there was none, I respond to real incidents end to end, and when a vulnerability lives in the code I fix it in the code.

- **DFIR & SecOps** at the core. Real DDoS incident handled end to end, coordinated external pentests, and hands-on triage from log to remediation.
- **SIEM deployment & threat detection** built from scratch: Wazuh on Kubernetes, Azure Log Analytics with KQL, custom rule architecture and dual-pass detection logic.
- **Software engineering background** (five years of dev) that lets me do AppSec remediation directly in code: reflected XSS analysis and fix on a PHP Symfony / React / Kubernetes stack.
- **GRC & compliance mindset**: DORA documentation on a four-axis framework, PSSI authoring, IAM and MFA enforcement.
- **Bilingual**: English C2 (TOEIC 900, a year at CSULB), Spanish A2.

> **Open To** — SOC Analyst, SecOps, and Incident Handler roles (CDI) across Cannes, Grasse, Monaco, and Sophia Antipolis. Available from September 2026.
